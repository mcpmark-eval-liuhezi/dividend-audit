# dividend-audit

Quarterly dividend audit for our investment club's portfolio. This repository archives the treasurer's dividend income review ahead of each club meeting.

## What this repo is for

The club holds four positions — Apple (AAPL), Coca-Cola (KO), Johnson & Johnson (JNJ), and ExxonMobil (XOM). For each quarterly income review, this repo records:

- The most recent quarterly dividend per share
- Total dividends paid per share over the trailing twelve months (TTM)
- The current dividend yield
- Whether the stock has had any splits since 2019

The per-holding findings live in `dividend-history.md`, which is added via the `dividend-findings` branch. Members weigh in on each holding in the review comments on the pull request before anything is merged into the club's records.
